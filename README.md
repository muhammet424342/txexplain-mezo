# TxExplain for Mezo

Plain-language explainer for **MUSD borrow positions (troves)** and **MUSD-related transactions** on **Mezo testnet**.
Written from 4 Nov 2026 onward for Mezo Buildathon wave 2 (Track 2). Read-only: no wallet, no keys, no transactions sent.

## What it does
- `GET /api/trove/<address>`: reads a borrower's trove and explains collateral (BTC), debt (MUSD, incl. interest and the 200 MUSD gas-compensation reserve), collateral ratio, liquidation price, how far BTC can fall before liquidation, and a risk label (LOW / MEDIUM / HIGH / LIQUIDATABLE).
- `GET /api/tx/<hash>`: decodes a Mezo tx (BorrowerOperations function, TroveUpdated / TroveLiquidated / Redemption / fee events, MUSD mint/burn/transfer) into one paragraph, linking to the borrower's trove.
- `GET /api/system`: BTC price, system collateral ratio (TCR), Recovery Mode flag, active trove count, minimum net debt.
- `GET /api/sample`: first trove in SortedTroves, for the demo button.
- `/`: demo page.
